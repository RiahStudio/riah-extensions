# Riah Brand Assets

This folder stores public-release brand assets for Riah Extensions.

## Icon System

- Extracted assets: `docs/brand/riah-icon-system/`
- Original source zip: `docs/brand/source/Riah icon system design.zip`
- SHA-256: `F4A0C687BEA007907BD5B9BB59F8AEB8116EC2A017B37344D614542FCE482775`

Use `docs/brand/riah-icon-system/icons/svg/` as the source of truth. The PNG
exports are included for reference and store surfaces that require raster
assets. Do not use the old placeholder extension icons for public releases.

The current extension-to-icon assignments are recorded in
`docs/brand/ICON-MAPPING.md`.

## Icon Rules

- Keep the near-black tile, inset hairline, and hot-pink glyph system.
- Use `riah-tile.svg` as the base for new extension-specific glyphs.
- Export required extension sizes from SVG after the glyph is approved.
