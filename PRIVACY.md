# Privacy

Riah Extensions are designed to be local-first.

## What We Collect

The extensions do not collect telemetry, analytics, browsing history, personal
data, or usage events for Riah Studio.

## Local Browser Storage

Some extensions store preferences in the browser's extension storage, such as
enabled/disabled hosts, zoom levels, language choices, thresholds, or export
settings. This storage stays inside the browser extension sandbox.

If browser sync is enabled, the browser provider may sync extension settings
through the user's browser account according to that provider's own sync
settings and privacy policy.

## External Pages

Some extensions open external pages only when the user asks them to:

- Riah Library Search opens the configured catalog or library search URL.
- Riah Timeline Exporter downloads a local CSV file from visible page content.
- Riah Studio and Buy Me a Coffee links open only when clicked in an extension
  popup or options page.

The extensions do not send data to a Riah Studio server.

## Tab Audio

Riah Volume Boost captures the active tab's audio only after the user adjusts
the popup controls in a Chromium browser. The stream is routed locally through
Web Audio for gain control. It is not recorded, saved, transmitted, or sent to a
Riah Studio server.

## Remote Code

The extensions do not load remote scripts, remote configuration, or remote
extension code.

## Contact

For privacy questions, use the contact path at <https://riahstudio.com/>.
