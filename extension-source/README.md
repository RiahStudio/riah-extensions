# Riah Extension Source

This folder contains the implemented extension source tree.

## Layout

- `shared/<slug>/` contains one extension per folder.
- `shared/brand-links/` contains the shared unobtrusive Riah Studio and Buy Me a
  Coffee footer.
- `shared/settings/` contains the shared browser-storage helper library.
- `specs/` contains implementation specs for the publishable extensions.
- `tests/run.js` runs static audits, unit tests, and browser smoke tests.
- `dist/` is generated by `npm run build` and is not committed.

## Commands

From the repository root:

```powershell
npm test
npm run build
npm run package:public
```

From this folder:

```powershell
npm test
npm run build
```

The build script copies each extension into `dist/chrome/<slug>/` and
`dist/firefox/<slug>/`, using the browser-specific manifest as `manifest.json`.
`Riah Volume Boost` is Chromium/Brave-only for publishing until a separate
Firefox audio implementation is built.
